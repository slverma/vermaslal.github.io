# Shambhu Lal Verma - Professional Profile

A professional portfolio website showcasing the experience and skills of Shambhu Lal Verma, Senior Full Stack Developer.

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository (if not already done):
```bash
git clone https://github.com/vermaslal/vermaslal.github.io.git
cd vermaslal.github.io
```

2. Install dependencies:
```bash
npm install
```

### Running the Application

#### Option 1: Express Server (Recommended)
```bash
# Development mode with auto-reload
npm run dev

# Production mode
npm start
```

#### Option 2: Simple HTTP Server
```bash
npm run serve
```

#### Option 3: Direct file access
Simply open `index.html` in your browser.

### Available Scripts

- `npm start` - Start the Express server in production mode
- `npm run dev` - Start the development server with auto-reload
- `npm run serve` - Start a simple HTTP server
- `npm run build` - No build process needed (static site)
